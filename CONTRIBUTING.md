# Contributing to HostelHub

Thank you for your interest in contributing to HostelHub!

To keep contributions organized and avoid duplicate or unnecessary pull requests, please follow this process.

## 1. Get Approval Before Starting

* Do not start implementing a feature, bug fix, or enhancement without prior approval from the maintainer.
* First, check the existing issues and open pull requests.
* Comment on the relevant issue describing your proposed approach.
* Wait until the maintainer approves the task or assigns it to you.

## 2. Issue Assignment

* Only work on issues assigned to you or explicitly approved by the maintainer.
* Do not assume that an open issue is available to work on.
* If you want to work on a new idea, open an issue and wait for approval before submitting code.

## 3. Pull Request Rules

* Pull requests submitted without prior approval may be closed.
* Do not submit duplicate fixes or unrelated changes.
* Keep each pull request focused on one approved task.
* Reference the relevant issue in your pull request description.
* Test your changes before submitting a PR.

## 4. Review Process

All pull requests are subject to maintainer review. The maintainer may request changes or close a PR if it is outside the approved scope.

Thank you for helping keep HostelHub organized and maintainable!
